# Статус проекта

_Обновлено: 27 июля 2026_

## Реализовано

- Многостраничный сайт Edifice: главная, услуги, проекты, технологии и качество.
- Адаптивная навигация и единый визуальный стиль.
- Каталог проектов с фильтрами, сортировкой, переключением сетка/список и счётчиком результатов.
- Модальное окно с детальной информацией по каждому объекту.
- Карта объектов на Яндекс Картах.
- Локальные фотографии проектов, логотип и favicon.
- Публичный домен `edifice-stroy.ru` и латинские маршруты `/services/`, `/projects/`, `/technologies/`.
- Прямые ссылки логотипа на `/` и рабочие якоря `#contacts` на всех основных страницах.
- SEO-метаданные, canonical, Open Graph, Twitter Card, JSON-LD, sitemap и robots.txt.
- Видимые хлебные крошки на внутренних страницах.
- Страница политики конфиденциальности и уведомление о необходимых cookie.
- Оптимизированные WebP-изображения, адаптивные варианты для мобильных устройств и локальный шрифт Inter.
- Яндекс Карты загружаются только при приближении пользователя к карте.
- Удалена тяжёлая клиентская зависимость React/Babel: интерактивность работает на нативном JavaScript.
- Проверены текущие фото: «ЖК Дмитров Сити» и «ЖК Афродита» соответствуют указанным объектам; замен не требуется.
- Пользовательские фото реновации на Лихачёвском переулке и Радужной улице размещены в карточках и модальных окнах.
- Для ЖК «Мытищи Сити» установлена предоставленная пользователем визуализация полукруглого дома с официального сайта объекта.
- Lighthouse после оптимизации: 86/100 mobile и 99/100 desktop локально; до оптимизации mobile был 26/100.

## Дальше

1. Опубликовать текущие изменения в `main`.
2. Повторить Lighthouse на опубликованном домене.
3. Проверить выпуск HTTPS-сертификата и включить принудительный HTTPS в GitHub Pages.
4. Добавить домен в Яндекс Вебмастер и Google Search Console.
5. Подтвердить права через DNS TXT или файлы/метатеги, выданные сервисами.
6. Передать в оба сервиса `https://edifice-stroy.ru/sitemap.xml`.

## Баги и технический долг

- `projects/index.html` содержит большой объём разметки, стилей, данных и JavaScript в одном файле; редактирование требует внимательной проверки.
- Нет автоматической проверки ссылок, изображений и визуальной регрессии.
- HTTPS-сертификат домена ещё не соответствует `edifice-stroy.ru`; до выпуска сертификата сайт стабильно открывается по HTTP.
- Исходные PNG/JPG сохранены в репозитории как архивные файлы, хотя публичные страницы используют облегчённые WebP.

## Точка продолжения

Сначала проверьте GitHub Pages и опубликованный домен после последнего коммита. Затем откройте Яндекс Вебмастер и Google Search Console в авторизованном браузере, добавьте ресурс `edifice-stroy.ru` и используйте предложенный сервисом способ подтверждения. Для DNS-подтверждения записи добавляются в панели DNS Premium RU-CENTER, после чего в оба сервиса отправляется sitemap.
